# Alchembright

[Alchembright](https://www.alchembright.com/)は、上松大輝（hiroki_u）の研究・仕事・活動と、日々の記録を紹介するWebサイトです。2003年頃にMovable Typeで始め、その後WordPressで運用してきたブログの記事や写真を引き継いでいます。

このリポジトリは、Alchembrightのサイト構成、記事、画像を管理しています。AstroとMarkdownを中心に構築し、GitHub Pagesで公開しています。
