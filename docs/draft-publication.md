# 下書きの匿名化と公開

利用者の2026-09-09の指示により、下書きは必ず上松本人が匿名化内容を確認した後に公開する。

- オリジナルは非公開の原本として保管し、上書きしない。元バックアップと別保管コピーのバイト一致を確認済み。
- 原文、匿名化案、変更理由を記事ごとに提示する。人名だけでなくハンドル、リンク先、場所、所属、引用などからの特定も確認対象。
- 表現に変更がない下書きも、公開承認を得るまで未公開とする。
- 承認は記事単位で記録し、承認対象の案のハッシュ、承認者、確認日時を保持する。案を修正した場合は再確認する。
- 承認済みのコピーだけをGitHubに追加する。過去に公開済みだったように見せず、当時の作成日と今回の初回公開日を区別する。
- 未承認の原文・案・照合結果・下書き一覧は public/、src/content/、公開Gitに置かない。

初回の確認資料作成時は12件すべて未承認。現在の公開可否は下記の本人確認結果を参照。migration/reports/private/draft-review/ に原文、案、比較資料、未承認の記録を保持。これはGit管理外であり、今回のデプロイに含まれない。

## 本人確認結果（2026-09-09）

確認資料の1・2は非公開を継続。3は匿名化せず元本文・リンクで公開、7・8は提示した匿名化案を採用、4・5・6・9・10・11・12も公開承認。承認済み10件だけを migration/reviewed/mt-drafts.json と src/content/restored/ に追加する。原本・非公開2件はGit管理外に保持。

MT記事のローカル管理IDは負数で、元のMT記事IDではない。旧公開URL不明のため original_url はnull。作成日と今回の公開日を区別する注記を表示する。
