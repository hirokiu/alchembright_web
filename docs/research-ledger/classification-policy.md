## 当初の提案

**本文を備えた研究論文は「論文」、要旨・解説・訂正等は「MISC」、発表行為は「講演・口頭発表等」**を基本とし、査読有無・査読範囲・掲載種別は独立した属性として記録する。

Researchmap公式FAQは査読有無だけで論文/MISCを分ける方式を現在の原則にしていない。分野の慣行と本人の判断を尊重する。研究会の知名度や権威、DOIの有無、J-STAGE掲載の有無だけでは分類しない。主催学会名は書誌的事実として保存し、格付けを台帳へ持ち込まない。

参照: [Researchmap FAQ](https://researchmap.jp/public/FAQ-1)。これは個人台帳の統一方針であり、所属大学の業績審査基準を置き換えない。大学DBではその大学の区分へ別途マッピングする。

| 対象 | 台帳subtype | Researchmap提案 | 査読 / 範囲 | 判断根拠 |
|---|---|---|---|---|
| SWO59・SWO62 | research_report | 論文 / 研究会・シンポジウム資料等 | なし / none | 研究内容を記述した本文あり。本人が査読なしを確認 |
| SWO56・SWO44 | research_report | 論文 / 研究会・シンポジウム資料等 | なし / none | 同じSWOの方針を適用、PDFから著者補完 |
| じんもんこん2024 | symposium_paper | 論文 / 研究論文（研究会、シンポジウム資料等）を候補 | あり / abstract | 2ページ概要を査読し、採択後に6/8ページ本文を提出。通常のCH研究報告とシンポジウム論文集を区別 |
| 情報知識学会2025の古事類苑・コミュニケーション論文 | conference_paper | 論文（現在の区分を保持、本人確認） | 未確認 / unknown | PDFには「第33回年次大会予稿」。学会誌の掲載だけで査読付き原著としない |
| コミュニケーション論文のエラータ | erratum | MISC（提案） | 適用外 / not_applicable | 原論文に対する訂正記事。新しい研究論文として数えない |

じんもんこんの掲載種別の正式な画面文言は本人がResearchmap更新時に選択する。「論文（その他学術会議資料等）」など大学DB独自の区分があってもマスターのsubtypeを変更せず、そのDBへの対応で扱う。

[じんもんこん2024公式募集](https://www.jinmoncom.jp/sympo2024/) は概要論文を対象にシングルブラインド査読・審査を行うと明記している。`peer_reviewed=yes` に加えて `peer_review_scope=abstract` を必ず記録し、WebやCVでも「概要査読あり」と表示する。全文査読と一括して数える場合は集計条件を明記する。

SWO59は [公式プログラム](https://www.sigswo.org/papers/59program) の発表日2023-03-10と、出版社発行日2023-03-17が異なる。現在のpublication.dateは後者。SWO62は発表日・発行日とも2024-03-23だが、巻は出版社記載の2023を維持する。

今回は書誌レコードの整備を行い、発表レコードを重複生成していない。発表の追加時は新しい安定IDを発行し、論文へのrelated_idsを付ける。論文と発表を同一件数として数えない。

`researchmap_category` は台帳側の提案区分、`sync.researchmap.url` は観測された現在の外部レコードを指す。じんもんこんやエラータは両者が異なる。本人の移動・登録後にURL/IDを更新するまでneeds_reviewを維持する。
