# 経歴の公開用要約

2026-09-09、提供された経歴文と実績紹介資料を参照し、aboutの「これまでの仕事」に経験分野の要約を追加。

会社名、関係者名、顧客名、サービス名、採択名、イベント名、具体的な成果名・数値・日付・場所を掲載しない。資料の画面写真やロゴは転用しない。実績を特定する年表や案件別ページを作らず、Web・モバイル・センサー／データ・研究教育に一般化する。匿名化は再特定不能を保証するものではないため、珍しい案件の特徴の組合せも避ける。

既存の公開プロフィール・研究者情報は今回追加する非公開資料とは別の内容として保持。原資料と対応メモは公開Gitに含めない。資料中の「近況」は作成時点の記述なので現在の所属や現行サービスとして扱わない。
