今日勉強したコマンドたち。

<span class="Apple-style-span"><span class="Apple-style-span">TRUNCATE TABLE</span></span>

> テーブルに含まれるデータを全削除。

<span class="Apple-style-span"><span class="Apple-style-span">OPTIMIZE TABLE</span></span>

> テーブルの最適化、デフラグ。  
> 上記のTRUNCATE TABLEで全削除をしたり、変数長行で何カ所も変更した場合に実行。  
> （VARACAHR、VARBINARY、BLOB、TEXTカラムを持つテーブル）
> 
> そんなに頻繁に実行しなくてもいいらしい。  
> 週に一度とか、月に一度くらい、な感じ。

<span class="Apple-style-span"><span class="Apple-style-span"><p></p><div><span class="Apple-style-span"><span class="Apple-style-span">ALTER TABLE</span></span></div><p></p></span></span>

> テーブル構成の変更。
> 
> ・カラムの追加  
> <span class="Apple-style-span">ALTER TABLE テーブル名 add カラム名 データ型;<br></span>  
> ・カラム名の変更  
> <span class="Apple-style-span">ALTER TABLE テーブル名 change カラム名(current) カラム名(new) データ型;<br></span>  
> ・カラム定義の変更

> <span class="Apple-style-span">ALTER TABLE テーブル名 change カラム名 カラム名 新たな定義;</span>

> ・カラムの削除  
> <span class="Apple-style-span">ALTER TABLE テーブル名 drop カラム名;</span>

ちぃ、覚えた。

そんなわけで、困ったら[リファレンス](http://dev.mysql.com/doc/refman/5.1/ja/alter-table.html)を見ればいいと思った。

ちぃ、覚えた。
