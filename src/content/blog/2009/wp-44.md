<p>日本語読めないないぁ、と思いながら我慢して使っていたサクラさんですが、<br />$HOME以下にvimを入れて使えば大丈夫、ということらしい。</p>
<p>こちらのページを参考にさせてもらいました。</p>
<p><a href="http://www.hazama.nu/t2o2/archives/002696.shtml">さくらインターネットの共用サーバに vim をインストールする</a> – <a href="http://www.hazama.nu/t2o2/">talk to oneself 2</a></p>
<p>というわけで、コピペみたいな感じだけど、手順をメモしておきます。</p>
<p><br />
＊）シェルはbashに変更してあります。</p>
<blockquote>
<pre class="code">% chsh -s /usr/local/bin/bash<br /></pre>
</blockquote>
<pre class="code"><br />まずは、ソースを置く場所などを作成。<br /></pre>
<blockquote><p>$ cd<br />$ mkdir $HOME/local/src</p></blockquote>
<p>ディレクトリを作成したら、最新版のソースをダウンロードして展開。<br />2009年8月12日時点では、vim-7.2が最新。</p>
<blockquote><p>$ cd $HOME/local/src<br />$ wget ftp://ftp.vim.org/pub/vim/unix/vim-7.2.tar.bz2<br />$ wget ftp://ftp.vim.org/pub/vim/extra/vim-7.2-extra.tar.gz<br />$ wget ftp://ftp.vim.org/pub/vim/extra/vim-7.2-lang.tar.gz</p></blockquote>
<p></p>
<blockquote><p>tar jxf vim-7.2.tar.bz2<br />tar zxvf vim-7.2-extra.tar.gz<br />tar zxvf vim-7.2-lang.tar.gz</p></blockquote>
<p>その後、修正パッチをダウンロード。<br />修正パッチは、解凍してできたディレクトリの中に、patchesディレクトリを作成し、<br />その中にダウンロードします。</p>
<blockquote><p>$ cd vim72<br />$ mkdir patches<br />$ cd patches<br />$ curl -O ‘ftp://ftp.vim.org/pub/vim/patches/7.2/7.2.[001-245]’</p></blockquote>
<p>ちなみに、修正パッチもたくさんあるので、ダウンロード時点での最新版までを<br />取得するようにします。<br /># ftp://ftp.vim.org/pub/vim/patches/7.0/ で確認しましょう。<br /># 2009年8月13日時点では、245が最新パッチでした。</p>
<p>パッチのダウンロードが終わったら、vimのソースがあるフォルダに戻って、パッチを当てます。</p>
<blockquote><p>$ cd ../<br />$ cat patches/7.2.* | patch -p0</p></blockquote>
<p>で、やっとこんふぃぎゃー。<br />よくある感じで、コンパイルしてインストールします。</p>
<blockquote><p>$ ./configure –enable-multibyte –enable-xim –enable-fontset \<br />–with-features=big –prefix=$HOME/local<br />$ make<br />$ make install</p></blockquote>
<p>.bash_profileにPATHを追加しておきましょう。</p>
<blockquote><p>PATH=$PATH:$HOME/bin:$HOME/local/bin<br />export PATH</p></blockquote>
<p>.bashrc にaliasを作って、viで呼べるようにして、とりあえず終了。</p>
<blockquote><p>alias vi=’vim’</p></blockquote>
<p>後は、お好みで.vimrcなんかを編集してください。<br />その辺りは、こちらを参考に。<br /><a title="ずんWiki - vim" href="http://www.kawaz.jp/pukiwiki/index.php?vim#cb691f26">ずんWiki – vim</a></p>
