<p>いろいろな理由で、昨夜からサーバ構築をしているわけですが、ここでもいろんな理由によりFedoraCore3を入れることに。<br />
<a href="http://www.balog.jp/">場log</a>のサーバは、RedHat9を使っているのですが、その系列だからまぁいいか、ってなノリでインストールし始めたらハマってしまいました。<br />
<a href="http://www.selinux.jp/">SElinux</a>とやらを知らなかった自分が悪いんだろうけど。<br />
そして、現在サーバ構築から12時間経過(12月23日13時20分現在)<br />
SElinuxの設定をしようと、YUM updateを行ったらお亡くなりになりました(12月23日14時20分現在)</p>
<p><br />
YUMというコマンドを行うために、KEYをimportしなければいけないらしい。</p>
<pre># rpm --import /usr/share/rhn/RPM-GPG-KEY-fedora
# yum install selinux-policy-targeted-sources
# audit2allow -d &gt; httpd.te
</pre>
<p>なんかこんな感じ。<br />
まじめに書いておかないとまた落ちたときに困るけど、そろそろ限界(12月23日18時45分現在)</p>
