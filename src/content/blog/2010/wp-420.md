忘れないように、インストール手順をメモしておきます。  
■環境  
CentOS 5.4  
TOSHIBA Dynabook SS  
HDD:80GB  
memory:768MB  
■準備  
sudo yum install java  
これが入っていればOK  
\-> java-1.6.0-openjdk-1.6.0.0-1.7.b09.el5.i386  
■インストール  
よくわかんないけど、バイナリが落ちてるのでそれを落としてくるだけ  
javaとかあんまり知らないからw  
今のstable版は0.6.1。  
本家サイトからダウンロードしてくる感じ。  
[The Apache Cassandra Project](http://cassandra.apache.org/)  
[apache-cassandra-0.6.1-bin.tar.gz](http://www.apache.org/dyn/closer.cgi?path=/cassandra/0.6.1/apache-cassandra-0.6.1-bin.tar.gz) を取得したら、適当な場所に配置して解凍して終了。
