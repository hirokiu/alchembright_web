<p>流行りにのって、Cassandraはじめました。<br />
とりあえずインストールから。<br />
（環境は、CentOS 5.4 32bitです。）<br />
cassandraはjavaで作られているので、javaがインストールされているかご確認を。<br />
バージョンは、1.6以上推奨とのことです。</p>
<blockquote><p># which java<br />
/usr/bin/java<br />
# java -version<br />
java version “1.6.0_0”<br />
OpenJDK Runtime Environment (IcedTea6 1.6) (fedora-23.b16.fc10-x86_64)<br />
OpenJDK 64-Bit Server VM (build 14.0-b16, mixed mode)</p></blockquote>
<p>インストールされていなければ、yum等で入れてください。</p>
<blockquote><p># sudo yum install java</p></blockquote>
<p>javaの確認ができたら、cassandraをGET。</p>
<blockquote><p># cd /usr/local/src<br />
# sudo wget “http://www.meisei-u.ac.jp/mirror/apache/dist/cassandra/0.6.2/apache-cassandra-0.6.2-bin.tar.gz”<br />
# sudo tar -zxvf apache-cassandra-0.6.2-bin.tar.gz
</p></blockquote>
<p>cassandraはバイナリで配布されているので、解答したら実行するだけです。<br />
簡単！</p>
<blockquote><p># cd apache-cassandra-0.6.2<br />
# ./bin/cassandra -f</p></blockquote>
